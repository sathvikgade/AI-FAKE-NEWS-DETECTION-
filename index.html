Algorithm Architectural Comparison

Theoretical breakdown of non-parametric, parametric, ensemble, and deep learning algorithms implemented in the project.

KNN

Non-Parametric

Calculates Euclidean/Cosine distance to 5 nearest neighbors in feature space.

  • High inference latency
  • Fails in high dimensions (58.6% Acc)
  • Simple implementation

Logistic Regression

Parametric Linear

Applies sigmoid function to linear decision boundaries over TF-IDF terms.

  • Extremely fast training & inference
  • High accuracy (96.90%)
  • Highly interpretable weights

Random Forest

Ensemble Trees

Combines 100 decision trees trained on random bootstrap samples of articles.

  • Top Accuracy (99.40%)
  • Prevents overfitting
  • Robust to sparse word matrices

Neural Network

MLP Classifier

Multi-Layer Perceptron with 50 hidden neurons and ReLU activation functions.

  • Learns non-linear word patterns
  • Strong accuracy (96.20%)
  • Requires longer training time
